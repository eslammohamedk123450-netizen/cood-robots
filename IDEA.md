# NOVA — Product Idea

NOVA is a personal digital companion for Islam, designed around a friendly character rather than a command dashboard.

The long-term vision is documented in NOVA_MASTER_VISION.md. The currently approved first release is defined by NOVA_V1_SCOPE.md. Those documents are the source of truth and should be updated when Islam approves new ideas.

Current V1 priorities:
- Voice-first, natural conversation in Egyptian Arabic.
- Soly (blue) and Soleen (pink), with distinct visual identity and personality.
- Full-body 3D character integration, expressive animations, gestures, and lip sync.
- Persistent, owner-controlled memory organized into notebooks/categories.
- Minimal settings for persona, owner display name, voice, and secure AI provider configuration.
- Text input only as a secondary accessibility option.

Do not add camera, face recognition, desktop/device permissions, alarms, smart home, or physical robot movement to V1.

Mandatory repository rules are in AGENTS.md and NOVA_EXECUTION_RULES.md. In particular, all work must remain on the existing main branch in this one repository. No new branch or copy is allowed without Islam's prior explicit permission.
