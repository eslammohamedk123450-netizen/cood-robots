# NOVA Desk Robot

واجهة ويب أولية لروبوت مكتبي تفاعلي، مبنية من المرجع البصري الموجود في `IMG-20261126-WA0000.jpg`. تحتوي على شخصيتي **سولي** و**سولين**، وجه متحرك، محادثة وأوامر تجريبية، نطق، ميكروفون، كاميرا، وصفحة هوية وإعدادات.

## التشغيل

يمكن فتح `index.html` مباشرة للتجربة الأساسية، أو تشغيل خادم محلي:

```bash
python3 -m http.server 4173
```

ثم زيارة `http://localhost:4173`. الكاميرا والميكروفون يحتاجان HTTPS أو localhost، وسيطلب المتصفح الإذن قبل الاستخدام.

## النشر على GitHub Pages

المستودع يحتوي على Workflow في `.github/workflows/pages.yml`. من إعدادات GitHub فعّل Pages باستخدام **GitHub Actions**. بعد كل Push إلى `main` سيُعاد النشر تلقائيًا.

## حدود النسخة التجريبية

الأوامر الحالية محاكاة داخل المتصفح. الكاميرا تثبت الوصول المحلي فقط ولا تعتبر نظام تعرف بيومتري. الإعدادات التي تدخلها في صفحة Settings تُحفظ في `localStorage` على الجهاز ولا يتم استدعاء Supabase أو AI فعليًا قبل إضافة Edge Function.

## الطريق الصحيح للـ Backend

استخدم Supabase للمستخدمين والصلاحيات والسجلات، ثم Edge Function تستقبل الأمر من الواجهة وتستدعي مزود الذكاء الاصطناعي من الخادم. لا تضع مفتاح AI سريًا في JavaScript أو GitHub Pages. عند إضافة التعرف على الوجه، استخدم descriptors محلية أو خدمة موثوقة مع موافقة المستخدم وسياسة حذف واضحة؛ لا تجعل الوجه عامل الأمان الوحيد.
